## FAILED `dev-administration/tests/test_caddy_utils.py::test_generate_caddy_agents_conf`

The test asserts a `handle_path` directive for the per-agent setup route, but
`generate_caddy_agents_conf()` emits a plain `handle`:

```

dev-administration/tests/test_caddy_utils.py:13: AssertionError
```

The generator produces `handle /agent/juan/setup { reverse_proxy 127.0.0.1:9080 }`.
The assertion expects `handle_path`. The two differ in whether the matched prefix
is stripped before proxying, so this is a real behavioural question about the
setup route, not merely a stale string in the test — whichever side is wrong,
someone has to decide which behaviour is intended.

The generator's output is what the **running** stack uses, so the shipped
behaviour is `handle`. That makes the test the more likely candidate for being
stale, but this has not been verified and must not be assumed.
