# Hand-authored definitions

Audience: whoever wires a pipeline. Job: say what belongs here rather than in
`pantheon-go/definitions/`.

Two directories, one registry. The split is not organisational, it is the
invariant:

| Directory | Owns | Written by |
|---|---|---|
| `pantheon-go/definitions/` | what an action **is** — its contract, policy and resource needs | generated by `ptn-gen emit`, drift-gated, never hand-edited |
| this directory | how actions are **wired**, and what they connect to | hand-authored |

Invariant 3 says edges are derived from references, never authored as entities.
`on:` and `then:` are those references. Go never emits them — a code generator
that could write an edge is a code generator that has become a DSL.

`ptn plan` takes both directories and validates them as one graph.
